How grading works

Worth being straight about this. Most exercises are checked by regex against the shape of your answer — they verify you wrote the right construct, not that your code runs correctly. SQL and JavaScript genuinely execute (sample data and a sandboxed worker), and Java compiles and runs for real if you start the optional local runner. Every exercise ships a Run locally panel with exact commands, and that is the ground truth.

Built with zero runtime dependencies — no framework, no bundler, no CDN. Each course builds to one self-contained HTML file you can open offline.
